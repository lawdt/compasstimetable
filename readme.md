# Расписание школы «Компас» (Бар)

Миниапп Telegram, который показывает расписание уроков по классам. Данные
берутся напрямую из опубликованной таблицы школы, так что отдельно ничего
поддерживать не нужно: поправили таблицу — приложение показывает новое.

- класс и программа обучения запоминаются (CloudStorage Telegram,
  синхронизируется между устройствами; вне Telegram — localStorage);
- вёрстка под телефон, светлая и тёмная темы подхватываются из Telegram;
- текущий урок подсвечивается;
- ссылка вида `?class=5&prog=ru` открывает конкретный класс и программу,
  минуя выбор, и не затирает сохранённые настройки;
- дни листаются свайпом по горизонтали: соседние дни едут вместе с текущим,
  поэтому переход видно (на компьютере — стрелками или горизонтальной
  прокруткой трекпада), день открывается с первого урока;
- тяга вниз от начала списка обновляет расписание;
- кнопка в шапке включает компактный режим: остаются одни уроки, а
  перемены, паузы, обед, конец дня и объявления скрываются; подвал при этом
  прижимается к низу экрана.

## Как это устроено

```
lib/sheet.mjs              разбор таблицы в JSON
lib/staff.mjs              подстраховка к разбору имён (см. ниже)
lib/subjects.mjs           расшифровка сокращённых названий предметов
lib/alice/                 навык Алисы: речь, выборка дня, настройки
netlify/functions/         /api/schedule, вебхук бота /api/bot и навыка /api/alice
public/                    сам миниапп: статика без сборки
scripts/                   локальный сервер, настройка бота, отладочный дамп
supabase/                  прежняя версия навыка, удаляется после переезда
android/                   приложение для Android
```

Читается HTML-версия публикации таблицы (`pubhtml/sheet`), а не CSV: только в
ней есть объединённые клетки и цвета фона. Из этого получается:

| В таблице | В приложении |
| --- | --- |
| объединение по вертикали | длительность урока |
| объединение по горизонтали | перечень классов: «5–9 кл.» |
| `предмет / предмет` + `имя / имя` | две подгруппы, по строке на каждую |
| буква `N` в узкой колонке справа | «2-я группа англ.» |
| `(6)`, `(маст.)`, `(библ.)` в конце | номер кабинета |
| занятие после последнего служебного блока | «платное доп. занятие» |
| длительность 70 минут и больше | «сдвоенный урок» |
| цвет клетки | преподаватель |

Двойные уроки разбираются позиционно: `Литература / Матем.` вместе с
`Кристина (5) / Т.В.` дают две подгруппы — «Литература, Кристина, каб. 5» и
«Матем., Т.В., без кабинета». Кабинет относится только к своей половине
класса, а не к уроку целиком. Первая строка идёт по российской программе
(пункт 1 легенды), поэтому порядок подгрупп сохраняется как в таблице.

Если слэш стоит только в именах, смысл зависит от второго преподавателя.
Татьяна В. ведёт украинскую программу, поэтому `Математика Над. / Т.В.` — это
всё то же деление, просто у половин одинаковое название предмета: карточка
показывает предмет один раз и обоих преподавателей, а выбор программы
оставляет нужного. Алла Г. в младших классах — второй педагог на том же
уроке, и `Матем. Ангелина / Алла Г.` делением не считается (в этих классах
двойных уроков нет вообще).

## Программа обучения

Переключатель рядом с классом сворачивает двойной урок до нужной половины:
«Российская» оставляет первую, «Украинская» — вторую, по умолчанию видно обе.
Показывается он только у классов, где деление по программам действительно
есть — сейчас это 4, 5, 6 и 8; у остальных шапка остаётся без лишней кнопки.

Программа определяется положением в клетке: первая половина — российская,
вторая — украинская. Отдельных признаков нет, потому что любая двойная клетка
в этой таблице означает именно это деление.

Букву `N` приложение привязывает к английскому, а не к уроку целиком: если
класс в это время делится, пометка «2-я группа англ. — Наталья» встанет на
английскую половину, а не на вторую подгруппу с другим предметом.

Деление английского на группы не связано с программой: часть класса
занимается у Mrs. Strock, часть у Натальи. Поэтому пометка видна при любом
выборе программы — и когда Наталья названа в клетке (`Eng. ... / N.`), и
когда о ней говорит только буква `N` в узкой колонке.

Номера уроков нумерует само приложение: в опубликованной таблице колонка
с номерами скрыта, а в исходной нумерация идёт с пропусками и повторами.

Названия предметов в таблице записаны по-разному («Матем.», «Мат.»,
«Математ.»), поэтому они приводятся к одному виду. Сначала работает то же
правило, что и с именами: сокращение разворачивается по полному написанию
из самой таблицы, ведь рядом почти всегда есть клетка с целым названием
(«Ист.» узнаётся по «История»). Так новое сокращение не требует правки
кода.

Словарь в `lib/subjects.mjs` нужен для того, что по префиксу не выводится:
многословных сокращений («Окр. мир», «Черн. яз.», «Р. яз.»), перевода
(«Нав. світ» → «Навколишній світ») и латиницы («Eng.», «En.»). Точка в
конце названия убирается, незнакомое название показывается как в таблице.

## Вторая половина дня

Обычные уроки заканчиваются до последнего служебного блока дня: у младших
классов это прогулка, у старших обед или самоподготовка. Всё, что стоит
после него, — активности второй половины дня, то есть дополнительные
занятия: они получают отдельный фон и пометку «платное доп. занятие»
(пункты 5 и 6 расшифровки). Обед в середине дня границей не служит — после
него у младших идут обычные уроки.

Сдвоенные уроки видно по длительности: обычный идёт 40-45 минут, сдвоенный
90-95, то есть занимает два звонка с переменой внутри. У такой карточки
цветная полоса слева разбита на два отрезка. Длинные занятия второй
половины дня сдвоенными не считаются — это кружки.

Звонки берутся из колонок времени. Их две — для младшей и старшей школы;
на каждую строку выбирается значение, не ломающее возрастание, поэтому
опечатки в таблице не сбивают порядок уроков.

Разбор занимает пару секунд, поэтому `/api/schedule` кэшируется на CDN
Netlify: 15 минут, дальше отдаётся устаревший ответ с обновлением в фоне.
Тяга вниз запрашивает данные с параметром `fresh=1` — у него окно кэша
10 секунд, только чтобы повторный жест не пересчитывал таблицу заново. Последний удачный ответ приложение держит в localStorage и
показывает сразу при открытии, а затем обновляет в фоне.

## Локально

```
npm run dev              # http://localhost:8888
npm run dump             # всё расписание в консоль
npm run dump -- 5        # только пятый класс
npm run dump -- --json   # разобранный JSON целиком
```

Вывод показывает то же, что видит человек в приложении: подгруппы
отдельными строками, номер урока, кабинет, платные и сдвоенные занятия.
Быстрее всего проверять так странную клетку в таблице.

Расписание с продакшна берётся обычным запросом:

```
curl -s https://compass-bar-schedule.netlify.app/api/schedule | jq .
```

## Как открыть миниапп в Telegram

Миниапп открывается только через бота — другого входа в Telegram нет. Но
запускать какой-либо код бота для этого не нужно, хватит @BotFather:

1. `/newbot` — создать бота, если его ещё нет;
2. `/newapp` — привязать миниапп к боту, указав адрес сайта. Появится
   ссылка `t.me/<бот>/<имя>`, её и можно давать родителям;
3. `/setmenubutton` — при желании ещё и кнопка в чате бота.

Токен нужен, чтобы бот сам отвечал на сообщения: на `/start` он присылает
кнопку запуска, на `/id` — идентификатор чата для формы сообщений об
ошибках. Положите `BOT_TOKEN` и `WEBAPP_URL` в `.env` и выполните:

```
npm run setup-bot
```

Скрипт пропишет вебхук, кнопку меню, команды и описания. Установка вебхука
заодно отбирает обновления у любого другого экземпляра бота: Telegram
отдаёт их только одному получателю, поэтому старый бот, работавший на
опросе, замолкает сразу — отдельно останавливать его не нужно.

В личной переписке бот отвечает на любое сообщение кнопкой миниаппа. В
группе — только на команды и обычной ссылкой: кнопку с миниаппом Telegram
в группах не разрешает.

## Деплой

1. Подключите репозиторий к Netlify. Сборка не нужна: `netlify.toml` уже
   указывает `publish = "public"` и папку функций.
2. Задайте `WEBAPP_URL` — адрес сайта, а также `BOT_TOKEN` и
   `OWNER_CHAT_ID`, если нужна форма сообщений об ошибках.

Другая таблица подключается переменными `SHEET_URL` (адрес публикации без
`/pubhtml`) и `SHEET_GID` (номер листа).

## Про имена преподавателей

Чтобы в карточке предмет и преподаватель были разными строками, имя нужно
отделить от названия урока. Список имён приложение выводит из самой
таблицы, поэтому новый преподаватель среди года ничего не ломает. Признаки
независимые, и каждый работает сам по себе:

1. в клетке с двумя и более слэшами последняя часть — всегда имя
   (`Литература / Матем. Кристина (5) / Т.В.`);
2. в клетке классного часа имя стоит сразу после «Кл. час»;
3. клетки одного цвета ведёт один человек, поэтому общий хвост названий
   внутри цвета — тоже имя;
4. предмет стоит в начале клетки, преподаватель в конце, значит слово,
   которое встречается только в конце и ни разу в начале, — имя.

Дальше сокращения сопоставляются с полными формами по префиксу в обе
стороны: «Крист.» узнаётся по «Кристина», «Александр» — по «Алекс.». Точка
в конце необязательна, в таблице попадается и «Т.В.», и «Т.В». Название
предмета именем стать не может — проверяется по словарю в `subjects.mjs`.

В `lib/staff.mjs` остались только те сокращения, которые встречаются в
единственной клетке и по структуре не вычисляются, плюс два правила про
конкретных людей: буква `N` (вторая группа английского у Натальи) и
Татьяна В. как преподаватель местной программы. Если имя нигде не
распозналось, урок просто показывается одной строкой — ничего не ломается.

## Сообщения об ошибках

Ссылка «Сообщить об ошибке» в подвале открывает форму, текст из которой
уходит владельцу в Telegram вместе с классом, днём и выбранной программой.
Нужны переменные `BOT_TOKEN` и `OWNER_CHAT_ID`; без них форма честно
отвечает, что отправка не настроена. Свой `OWNER_CHAT_ID` можно узнать,
отправив боту команду `/id`.

Подпись `initData` из Telegram проверяется по токену бота: сообщение из
миниаппа приходит с именем отправителя, отправленное со стороны — с
пометкой, что подпись не сошлась. Текст обрезается до 1000 символов.

## Навык Алисы

Отвечает, какие уроки завтра или в названный день. Класс, программа и
признак «рассказывать ли о дополнительных занятиях» спрашиваются один раз
и хранятся в самой Алисе — отдельной базы у навыка нет.

Навык работает как функция Netlify рядом с ботом и берёт расписание из
того же `/api/schedule`, что и миниапп, а не разбирает таблицу сам: разбор
занимает пару секунд, а у Алисы на ответ около трёх. Ответ API лежит в
кэше CDN, поэтому запрос дешёвый.

```
netlify/functions/alice.mjs   вебхук: разбор реплики и сборка ответа
lib/alice/schedule.mjs        загрузка расписания и выборка дня
lib/alice/speech.mjs          разбор речи и словесные обороты
lib/alice/store.mjs           чтение и запись настроек в хранилище Алисы
```

Класс распознаётся среди тех, что есть в таблице, а не по зашитому списку:
появится новый класс — навык подхватит его вместе с расписанием. «Второй»
без буквы переспрашивается.

### Где лежат настройки

Всё, что навык возвращает в `user_state_update`, Алиса присылает обратно в
`state.user` со следующим запросом, у каждого пользователя своё. Для
устройства, где не выполнен вход в аккаунт, то же делает
`application_state`. Настройки записываются одним объектом под одним
ключом `settings`: `user_state_update` дописывает ключи по одному, а
`application_state` заменяет состояние целиком, и с единым объектом оба пути
ведут себя одинаково.

Хранилище работает, только если в Яндекс.Диалогах включена опция
«Использовать хранилище данных в навыке». Без неё Алиса не присылает
`state`, и навык отвечает, что запомнить класс ему негде, — иначе
настройка ходила бы по кругу на первом вопросе. Какие разделы состояния
пришли, функция один раз за запуск пишет в лог (`alice state: …`).

### Подключение в Яндекс.Диалогах

1. [dialogs.yandex.ru/developer](https://dialogs.yandex.ru/developer) →
   создать диалог → «Навык в Алисе»;
2. Backend → Webhook URL:
   `https://compass-bar-schedule.netlify.app/api/alice`;
3. включить «Использовать хранилище данных в навыке»;
4. Доступ — приватный, пока навык нужен только вам;
5. Вкладка «Тестирование» позволяет разговаривать с навыком, не отправляя
   его на модерацию.

### Локальный прогон

```
node scripts/alice-local.mjs setup   диалог настройки
node scripts/alice-local.mjs ask     вопросы про дни
node scripts/alice-local.mjs other   вопросы про чужой класс
node scripts/alice-local.mjs escape  выход из настройки
node scripts/alice-local.mjs second  класс с буквой
```

Скрипт вызывает функцию напрямую и сам изображает хранилище Алисы, так что
проверять реплики можно без развёртывания. Расписание берётся с боевого
сайта; другой адрес задаётся через `SCHEDULE_URL`.

## Приложение для Android

Оболочка вокруг той же страницы: статика миниаппа лежит внутри apk, поэтому
окно открывается сразу и без сети, а расписание подгружается с сайта — то
есть его изменения не требуют переустановки.

```
./scripts/build-apk.sh                     # debug-сборка
./scripts/build-apk.sh :app:assembleRelease
```

Готовый файл — `android/app/build/outputs/apk/debug/app-debug.apk`.

Отдельный скрипт нужен из-за JDK: Android Gradle Plugin принимает 17–21, а в
системе обычно стоит свежее. Скрипт берёт JDK, который приносит с собой
Android Studio.

Статику в репозитории не дублируем: задача `syncWeb` копирует `public/` в
assets перед каждой сборкой, подменяет `config.js` на адрес сайта и вырезает
подключение скрипта Telegram — без него страница не считает себя миниаппом.

Пара вещей, которые приходится держать в голове:

- страница внутри приложения открывается с локального адреса, поэтому
  `/api/schedule` и `/api/report` отдают `Access-Control-Allow-Origin`;
- локальные файлы отдаются через `WebViewAssetLoader` по https-адресу, а не
  через `file://`: так у страницы стабильный источник и `localStorage`
  переживает обновления приложения;
- кнопка «назад» сначала закрывает открытую шторку — приложение спрашивает
  об этом саму страницу через `window.__androidBack`.
